# infra

Инфраструктурная директория.

## 🔹 Что делает

Содержит Docker Compose конфигурацию для разработки и тестирования:

- **PostgreSQL** – база данных с указанным пользователем, паролем и базой (`.env` используется для конфиденциальных данных)
- **Redis** – кэш/очередь, защищён паролем
- **MinIO** – локальное S3-хранилище с веб-консолью
- Автоматическое создание бакета `corpbucket` в MinIO
- Все сервисы подключены к приватной сети Docker (`infra_network`), PostgreSQL и Redis **не доступны снаружи**

## ⚡ Быстрый старт

ВАЖНО! Репозиторий должен быть развернут в файловой системе Linux! 

1. Копируйте файл `.env.example` и переименуйте копию в `.env`:
   ```bash
   cp .env.example .env
2. Заполните .env своими доступами
3. В своем дистрибутиве Linux (Ubuntu/Debian..) установите утилиту "make" командой
   ```bash
   sudo apt install make -y
4. Для запуска всех контейнеров, в консоли выполните команду
   ```bash
   make up
5. Для остановки всех контейнеров, в консоли выполните команду
   ```bash
   make down
   
# Kafka Topics Creator (для apache/kafka)

Скрипт автоматически создаёт все топики из файла `kafka-topics.txt`.

#### Что нужно

- Docker запущен
- Контейнер с Kafka на образе `apache/kafka` (любой версии)
- Порт 9092 проброшен наружу (`ports: - "9092:9092"` в docker-compose.yml)

### Как пользоваться:

#### Linux / macOS / Git Bash (Windows)
 1. Добавь в kafka-topics.txt свои топики

 2. Дай права на запуск
    ```bash
      chmod +x create-topics.sh 
 3. Запусти
       ```bash
      ./create-topics.sh
      ```

## Список команд make

| Команда                     | Что делает                            |
| --------------------------- | ------------------------------------- |
| `make up`                   | Поднять все контейнеры                |
| `make build`                | Пересобрать контейнеры и запустить их |
| `make down`                 | Остановить все контейнеры             |
| `make restart`              | Перезапустить контейнеры              |
| `make logs`                 | Просмотр логов контейнеров            |
| `make ps`                   | Список запущенных контейнеров         |
| `make shell service=<name>` | Зайти в контейнер (например, `minio`) |
| `make clean`                | Удаляет контейнеры и volume'ы         |
| `make prune`                | Полная очистка Docker (внимательно!)  |


## Взаимодействие с репозиторием

2. Если есть необходимость в добавлении новых доступов, добавьте его в .env.example и в docker-compose.yaml через ${НАЗВАНИЕ_ДОСТУПА}
