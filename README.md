# infra
* Инфраструктурная директория
* Запускает базу данных для локальной разработки

запусти run.sh (`bash run.sh`) чтобы создать БД, MinIO, Redis, а так же кафка-кластер

пропиши свои топики кафки в дополнение к существующим в **`application.yml`**

запусти KafkaConfigApplication один раз, чтобы создать топики

чтобы начать сначала, сперва запусти `stop.sh` или вручную удали в докере все кафка контейнеры и его volumes
