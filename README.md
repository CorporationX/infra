# infra
* Инфраструктурная директория
* Запускает базу данных для локальной разработки
* Запускаем run.sh
* Кафка UI поднимается http://localhost:8989/
* В Скрипте init-kafka.sh через функцию create_topic_if_not_exists добавляются новые топики
* Через бины топики в коде НЕ создаем
* Если нужно создать новый топик, добавляем через скрипт новую функцию create_topic_if_not_exists
* Далее кафка должна быть запущена в докере, после чего в docker-compose.yaml запускаем команду init-kafka - топик добавился
* Если в задаче вы создали новый топик - скажите это коллегам и обновите скрипт, иначе кафка будет искать топик и упадет
