# Infrastructure

Инфраструктурная директория для локальной разработки микросервисов.

## Описание

Этот репозиторий содержит Docker-конфигурации для запуска всей необходимой инфраструктуры в среде разработки.

## Сервисы

| Сервис | Порт | Описание | UI/Console            |
|--------|------|-----------|-----------------------|
| PostgreSQL | 5432 | Основная реляционная БД | -                     |
| Redis | 6379 | Кэш и брокер сообщений | -                     |
| Redis Insight | 5540 | Визуализация и управление Redis | http://localhost:5540 |
| MinIO | 9000, 9001 | S3-совместимое object storage | http://localhost:9001 |
| Zookeeper | 2181 | Координация Kafka | -                     |
| Kafka Broker | 9092 | Брокер сообщений | -                     |
| Schema Registry | 8087 | Реестр Avro схем | -                     |
| Control Center | 9021 | Мониторинг Kafka кластера | http://localhost:9021 |

## Быстрый старт

### Предварительные требования
- Установленный Docker

### Запуск всей инфраструктуры

```bash
# Запуск всех сервисов в фоновом режиме
docker-compose up -d

# Просмотр логов всех сервисов
docker-compose logs -f

# Остановка всех сервисов
docker-compose down
